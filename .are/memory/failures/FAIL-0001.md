# FAIL-0001 — Documentation and dashboard point at a stale second checkout

| | |
|---|---|
| **Date found** | 2026-08-19 (ARE bootstrap) |
| **Severity** | MEDIUM |
| **Category** | environment-drift, documentation |
| **Area** | repository layout, `README.org`, `AGENTS.md`, `lisp/init-dashboard.el` |
| **Origin** | pre-existing |
| **Status** | OPEN — needs an operator decision |

## Symptoms

Two working trees of `git@github.com:Celsuss/Ratatoskr-emacs.git` exist on this machine:

| Path | Branch | HEAD | State |
|---|---|---|---|
| `/home/jens/.config/emacs` | `dev` | `1d38bd8` | live config, 6 modified/untracked paths |
| `/home/jens/workspace/Ratatoskr-emacs` | `dev` | `ecdd05e` | clean, 4 commits behind |

Neither is a symlink to the other. Emacs loads `~/.config/emacs` (the XDG default), so
that is the live one.

Every piece of documentation names the other one:

- `README.org` §Clone: `git clone … ~/workspace/Ratatoskr-emacs`
- `README.org` §Run: `emacs --init-directory ~/workspace/Ratatoskr-emacs`
- `AGENTS.md` §Emacs Commands: same path, three times
- `AGENTS.md` §Testing Your Changes: same path
- `lisp/init-dashboard.el:11` — `rata-dashboard-git-repos` watches `~/workspace/Ratatoskr-emacs`

## Root cause

The repository was originally cloned to `~/workspace/Ratatoskr-emacs` (as the README
instructs) and later also placed at `~/.config/emacs`, which is where Emacs picks it up
without `--init-directory`. The docs were never updated, and neither checkout was removed.

## Why it escaped detection

Nothing verifies documented paths. `just run` uses `init_dir := "."`, so it is correct from
*either* directory — the drift is invisible to every existing check, and to the operator
as long as they only ever run `just run` from the right shell.

## Impact

- The dashboard reports git status for a checkout nobody is editing, so it shows "clean"
  while the live config has uncommitted work.
- Anyone following `README.org` or `AGENTS.md` — including a future agent session — edits
  files that Emacs never loads, and the change appears to do nothing.
- Two trees on the same branch can diverge and produce a confusing merge.

## Fix

**Not applied.** Choosing the canonical path is the operator's call: deleting a checkout,
or replacing one with a symlink, or updating five documentation references are three
different decisions with different consequences. All are outside "do not change
application functionality during bootstrap".

Recommended, in order of preference:

1. Delete `~/workspace/Ratatoskr-emacs` (it is clean and pushed, so nothing is lost) and
   update the five references to `~/.config/emacs`.
2. Or replace `~/workspace/Ratatoskr-emacs` with a symlink to `~/.config/emacs`, and leave
   the docs alone.

## Regression protection

`scripts/are-audit.sh` check `docs-paths`: fails if `README.org` or `AGENTS.md` reference
an `--init-directory` path that is not the repository this audit is running in. This
converts the drift from invisible to loud, without deciding which path is right.

## Verification improvement

The audit now also reports which checkout it is running in, so a session cannot silently
work in the wrong tree.
