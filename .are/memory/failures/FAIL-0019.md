# FAIL-0019 — The agent-shell Enter-key fix was written against an upstream this machine has never had, and turned the first agent-shell of a session into a `void-variable` error

| | |
|---|---|
| **Date found** | 2026-09-13 |
| **Severity** | MEDIUM |
| **Category** | environment-drift, verification-gap |
| **Area** | `lisp/init-llm.el`, `tests/run-tests.el`, `elpaca/sources/agent-shell/` |
| **Origin** | introduced by `3492fb0` (2026-09-04), latent on this machine from the day it was committed |
| **Status** | FIXED — guard and skip 2026-09-13; agent-shell, shell-maker and acp updated by the operator the same day, both tests run and pass |

## Symptoms

Two ERT failures on every run since 2026-09-04, both
`(void-variable agent-shell-ui-fragment-map)`:
`rata-test-agent-shell-fold-chrome-answers-gui-return` and
`rata-test-agent-shell-return-still-submits-off-chrome`. The task brief for the
Emacs 31.1 rebuild assumed they were stale-artifact consequences; they survived the rebuild
untouched.

The same error is the real runtime defect: the `with-eval-after-load 'agent-shell-ui`
body in `init-llm.el` ran `define-key` on the void variable, so the first
`(require 'agent-shell)` of a session — i.e. the first agent shell the operator opened —
signalled inside `eval-after-load-helper`. The ERT backtrace is exactly that call chain.

## Mechanism

`agent-shell-ui-fragment-map`, `agent-shell-ui-make-foldable-text` and
`agent-shell-ui-toggle-fragment` were added to agent-shell upstream on **2026-08-14**. The
clone in this checkout is `429d191` (2026-03-27); the one in `~/.config/emacs` is `9515f83`
(2026-03-26); neither reflog shows a fetch since the clone. On those versions each fold
carries its own anonymous keymap from `agent-shell-ui-make-action-keymap` (`RET` and
`mouse-1` only), so there is no shared map to extend — and the GUI `<return>` bug that
L-035 describes is simply still present.

The commit says the tests were "verified by breaking it". They cannot have passed on this
machine at any point: `agent-shell-ui-make-foldable-text` does not exist here, so the test
would have errored, not failed. They passed on another machine whose clone was newer.
**There is no elpaca lockfile, so each machine's clone is its own vintage** — the same
gap FAIL-0015 §"Remediation" names when it rules out `just clean`.

Nothing caught it for nine days because the failing tests were being read as "the two
pre-existing agent-shell failures" (the 2026-09-12 mail session recorded exactly that and
moved on), and because the ERT step had, separately, been aborting before its summary line
([FAIL-0021](FAIL-0021.md)) — so no run since 09-08 printed a `Ran 103 tests` line for
anyone to read.

## Remediation

- `lisp/init-llm.el` — the `define-key` is guarded by `(boundp 'agent-shell-ui-fragment-map)`;
  the else branch is a `message` naming this record. An `eval-after-load` body must not be
  able to signal: it runs inside someone else's `require`.
- `tests/run-tests.el` — `rata-test--agent-shell-needs-fragment-map` `ert-skip`s both tests
  when the installed agent-shell lacks the API, with the upstream date and the remedy in the
  skip reason. A skip that says "update the package" is honest; a failure that said
  `void-variable` read like a broken config and sent two sessions in the wrong direction.

The operator ran `elpaca-update agent-shell` the same day. It failed its version check —
`shell-maker installed version (0 89 2) lower than min required 0.97.3` — because
`elpaca-update` moves one package and not its dependencies; `shell-maker` and `acp` (same
author, released together) had to be updated first, then `elpaca-rebuild agent-shell`.
With the fix live, the *second* test failed the same way one package further along:
its expected commands (`shell-maker-submit` in normal state, `newline` in insert) are
evil-collection's `repl-submit` theme and `shell-maker` module, upstream since mid-2026
and absent from the March clone here, where Enter off the chrome is `evil-ret` /
`agent-shell-submit`. The test now asserts the invariant the fix must keep — off the
chrome neither spelling of Enter is the fold toggle and `RET` is still a command — instead
of one evil-collection vintage's key theme, and was re-verified by widening the binding
into `agent-shell-mode-map` and watching it fail.

## Regression protection

The skip *is* the protection for the config: a future clone with the API runs the tests in
full. The class — "fix verified against a package version this machine does not have" — has
no gate short of a lockfile, which D-005 records as the operator's accepted trade.
