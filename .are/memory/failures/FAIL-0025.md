# FAIL-0025 — `just compile` could not find a sibling module

- **Severity:** MEDIUM (CI red on `Byte-compile (Syntax only)`)
- **Class:** verification-gap
- **Introduced:** commit 2499049 (B6, `init-agent-worktree.el` does `(require 'init-agent-center)`), found 2026-10-11 from CI.
- **Symptom:** `Error: Cannot open load file ... init-agent-center`, then `COMPILE FAILED: 1 file(s)`. The log is buried under `Cannot load <pkg>` noise (demoted use-package messages, not failures), which makes the cause look like whichever package is printed last.
- **Cause:** `compile`/`check` compile each file in a bare `emacs --batch` with no `lisp/` on `load-path`; `init.el` adds it only at runtime. It was the first module to require a sibling.
- **Why not caught:** the pre-commit hook runs `are-verify fast`, which does not compile.
- **Fix:** `-L lisp` in the `compile` and `check` recipes; `are-audit` check `compile-has-lisp-on-load-path`.
