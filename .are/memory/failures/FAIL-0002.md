# FAIL-0002 — yasnippet startup warning from an obsolete snippets directory

| | |
|---|---|
| **Date found** | 2026-08-19 (ARE bootstrap) |
| **Severity** | LOW |
| **Category** | configuration, obsolete-api |
| **Area** | `lisp/init-snippets.el` |
| **Origin** | pre-existing |
| **Status** | FIXED, with a regression test |

## Symptoms

Every startup, including every `just test-ert` run, emits:

```
[yas] Check your `yas-snippet-dirs': /home/jens/.config/emacs/elpaca/builds/yasnippet/snippets is not a directory
[yas] Prepared just-in-time loading of snippets with some errors.  Check *Messages*.
```

Twice, in fact — the message appears once per `yas-reload-all`.

## Root cause

`lisp/init-snippets.el` set:

```elisp
(setq yas-snippet-dirs
      (list (expand-file-name "snippets" user-emacs-directory)
            'yas-installed-snippets-dir))
```

`yas-installed-snippets-dir` is declared in `yasnippet.el:160` as
`(expand-file-name "snippets" yas--loaddir)` and marked obsolete on the very next line
(`yasnippet.el:161`, `make-obsolete-variable`). Upstream yasnippet no longer ships bundled
snippets, so `elpaca/builds/yasnippet/snippets` does not exist — verified absent.

The entry was also redundant: `yasnippet-snippets.el:52-53` already does
`(add-to-list 'yas-snippet-dirs 'yasnippet-snippets-dir t)` for itself, so the community
snippet collection was never coming from the obsolete variable in the first place.

## Why it escaped detection

`yas-reload-all` warns and continues; it does not signal. `rata-load-module` therefore has
nothing to catch, `rata--failed-modules` stays empty, and `just test-ert` passes with the
warning printed in its own output. Nothing asserted that entries in `yas-snippet-dirs`
resolve to real directories.

## Fix

Applied: dropped the obsolete symbol, leaving the repo's own `snippets/` directory.
`yasnippet-snippets` continues to register itself.

```elisp
;; `yas-installed-snippets-dir' is obsolete and points at a directory upstream
;; no longer ships; `yasnippet-snippets' adds its own dir to `yas-snippet-dirs'.
(setq yas-snippet-dirs
      (list (expand-file-name "snippets" user-emacs-directory)))
```

## Regression protection

`rata-test-yas-snippet-dirs-exist` in `tests/run-tests.el`: resolves every entry in
`yas-snippet-dirs` (symbols included, which is how yasnippet stores them) and asserts each
is an existing directory. Fails if anyone re-adds a phantom path.

## Verification improvement

The class of bug — *a package warns instead of signalling, so `rata-load-module` cannot see
it* — is recorded in [../LESSONS.md](../LESSONS.md) as L-002. Warnings in `just test-ert`
output are now treated as findings, not noise.
